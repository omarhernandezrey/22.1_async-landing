# Portafolio Profesional - Omar Hernández Rey

Este repositorio contiene el código fuente de mi portafolio profesional, diseñado para mostrar mis habilidades, proyectos y experiencia como Ingeniero de Software y Full Stack Developer.

## 🚀 Características

-   **Diseño Responsivo:** Adaptado para dispositivos móviles, tablets y escritorio.
-   **Modo Oscuro/Claro:** Soporte nativo para preferencias de sistema y cambio manual.
-   **Integración Multimedia:** Reproducción de videos de YouTube directamente en la página.
-   **Descarga de CV:** Acceso directo a mi hoja de vida en formato PDF.
-   **SEO Optimizado:** Etiquetas meta configuradas para mejorar la visibilidad en buscadores y redes sociales (Open Graph, Twitter Cards).
-   **Navegación Fluida:** Menú de navegación con efectos de vidrio (Glassmorphism) y desplazamiento suave.

## 🛠️ Tecnologías Utilizadas

-   **HTML5:** Estructura semántica.
-   **Tailwind CSS:** Estilizado moderno y utilitario.
-   **JavaScript (Vanilla):** Lógica de interacción y consumo de APIs.
-   **Vite:** Empaquetador y servidor de desarrollo rápido.

## 📦 Instalación y Uso

1.  Clonar el repositorio:
    ```bash
    git clone https://github.com/omarhernandezrey/22.1_async-landing.git
    ```
2.  Instalar dependencias:
    ```bash
    npm install
    ```
3.  Iniciar el servidor de desarrollo:
    ```bash
    npm run dev
    ```
